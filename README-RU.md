# Streamly Cinema — билеты с QR-кодом и отправкой на e-mail

## Запуск локально
1. Установите Node.js 18 или новее.
2. В этой папке выполните `npm install`.
3. Скопируйте `.env.example` в `.env` и укажите данные SMTP (инструкция ниже).
4. Запустите `npm start`.
5. Откройте http://localhost:3000.

## Как работает билет
- После оформления билет сохраняется на сервере в `tickets.json`.
- QR-код отображается на сайте в разделе «Мои билеты» и в предварительном просмотре.
- При настроенном SMTP письмо отправляется на указанный e-mail; QR-код вложен как PNG, а также есть ссылка на страницу билета.
- Если SMTP ещё не настроен или почтовый сервер временно недоступен, билет всё равно сохраняется на сайте, а интерфейс сообщает, что письмо не отправлено.

## Настройка Gmail для отправки писем
1. Используйте Gmail-адрес, к которому у вас есть доступ.
2. В Google Account включите двухэтапную аутентификацию.
3. Создайте **пароль приложения** Google (это не обычный пароль от аккаунта).
4. Заполните `.env`:
   - `SMTP_USER` — ваш Gmail-адрес.
   - `SMTP_PASS` — пароль приложения Google без пробелов.
   - `MAIL_FROM` — имя и тот же адрес отправителя.
5. Перезапустите сервер.
6. Откройте `http://localhost:3000/api/health`. Поле `smtpConfigured` должно быть `true`.

Никогда не публикуйте `.env` и не отправляйте пароль приложения другим людям.

## Публикация сайта
Чтобы ссылка из письма открывалась не только на вашем компьютере, разместите сайт на хостинге с HTTPS и задайте `PUBLIC_BASE_URL` равным публичному URL сайта, например `https://your-site.onrender.com`.

**Важно:** файл `tickets.json` подходит для небольшого демонстрационного проекта. На хостингах с временной файловой системой данные могут пропасть после перезапуска или нового развёртывания; для production лучше подключить постоянный диск или базу данных. Сам QR-код открывает страницу билета, он не является платёжным подтверждением.
